# ワークフローエディタ

ここでワークフローエディターの仕様とUIデザインを検討する。
最終的にはagdevworldに組み込むが、現時点では独立した機能として実装し検証する。

ワークフロー自体はjsonもしくはYAML形式による一個のファイルで定義する。
それを解釈してUIで表示し編集する。

UIでなくては編集できないようなものではなく、必要であればテキストエディタで直接編集することも可能であること。
また、人間とエージェントが共同で編集するが、最初はUIにはエージェントの対話機能は作らず、エージェント付きIDEで対話しながら編集し、それをUIに反映させるという設計にする。

エージェントへの指示と人間の直接操作を交えながら、エージェントのファイル操作、人間のUI操作が交互に行われるイメージだ。ただ人間が必ずしもエージェントの編集を待って操作するとは限らないので、その点は考慮する必要がある。

# ワークフロー

ワークフローの構成要素は以下の通りで、ワークフロー定義ファイルにはこの要素が全て含まれる。

1. ワークフローの目的や意図の説明テキスト。このテキストをTruthとして、それ以外はその実現のための解釈という位置付け。
2. ワークスペースにgit submodulとして追加するリポジトリ。読み取りのみ許可するreadonly編集も許可するeditableの２種類。
3. ワークフローのノードの説明テキスト
4. ワークフローの実行手順を表す何らかの表現(どういうフォーマットにするか迷い中)
5. 1の説明テキストとワークフロー定義が作者によって承認されたかどうか
