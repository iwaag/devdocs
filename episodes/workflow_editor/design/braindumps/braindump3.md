# project

ワークフローはプロジェクトのワークスペース内で実行される。projectの実体はgitリポジトリであり、慣習的にpj-プレフィックスをリポジトリ名に持つ。ワークスペースはそれをファイルシステムに展開した状態で、一つのプロジェクトが複数のワークスペースに展開されうる。

プロジェクトは以下の要素をもつ。

1. ルートのgitリポジトリと.gitignoreファイル
2. git submodulとして追加するリポジトリ。study/フォルダの下にstudyリポジトリをクローン、wedo/フォルダの下にwedoリポジトリにクローン、それ以外は自由。

実際にPCのファイルシステムに展開されるワークスペースは以下が加わる。

3. ignoreされる.local/フォルダ

現時点ではワークフローはprojectの内部で占有され、project間で共有する予定はない。

# UIの要件

1. プロジェクトの展開するサブリポジトリ一覧が表示されている。
2. プロジェクトが展開されているPC一覧が表示されている。
3. ワークフロー一覧は表示されている。
