# p4 Deus Ex Machina log

One line per event where the Omni Agent acted inside the request (posted, accepted, nudged,
un-✔'d, edited, deployed) — only ever on the Developer's ask. Reads (trace, board, `/healthz`,
logs, mirror) are not events.

Format: `time (UTC) | who asked | what the Omni Agent did | cause class | evidence`

Cause classes (from robust_workflow p3 ex1's candidate list): **rescue follow-up**, **missed
completion record**, **change contamination**, **duplicate work**, **silent stall**, **returned
change**, **false claim**, **missing tool/permission**, **other** (say what).

Observations that needed no action (e.g. a false claim that was left uncorrected, as the plan
says for Front's stale "not integrated") are listed under *Observed, no action* with the same
format and `—` in the action column; they count toward the class tally, not toward the DEM count.
